# Identidad visual · Torna Rehabilitación Urbana

Fuente: paleta y logos entregados por el cliente (2026-10-21).

## Colores

| Token Tailwind | Color | Uso |
|---|---|---|
| `torna` | `#0B1F3A` Azul Torna | Principal: encabezado, botones, textos y bloques destacados |
| `torna-700` | `#1A3358` | Hover de botones (derivado) |
| `rojo` | `#E50101` Rojo Torna | Acento: "lo que se rehabilita". Línea bajo el encabezado, enlaces, meta, alertas |
| `rojo-oscuro` / `rojo-claro` | `#B30000` / `#FDECEC` | Texto y fondo de alertas (derivados) |
| `medio` | `#6D7989` Azul medio | Solo elementos grandes o decorativos |
| `medio-texto` | `#5B6675` | Texto secundario pequeño (derivado: el azul medio no alcanza contraste AA, 4,42:1) |
| `piedra` | `#EBEDEF` Gris piedra | Fondos de apoyo, etiquetas |
| `fondo` | `#F5F6F8` | Fondo general de la app |
| `borde` | `#DDE1E6` | Bordes de tarjetas |
| `verde`, `ambar` | `#2F7D4F`, `#8A5A0E` | Solo semáforo (estados funcionales, fuera de la paleta de marca) |

## Logos (`public/brand/`)

- `torna-logo-oscuro.png`: fondo Azul Torna. Para encabezado y bloques azules.
- `torna-logo-claro.png`: fondo blanco. Para fondos blancos y el PDF de la ficha.
- `src/app/icon.png`: ícono de la pestaña (solo el edificio).

Los archivos originales no tienen transparencia: usar cada logo sobre su color de fondo.
